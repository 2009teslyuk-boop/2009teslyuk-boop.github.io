# Портфоліо

Чотири демо‑сайти на HTML, CSS та JavaScript.

- **Orchard** — магазин техніки Apple: каталог, кошик, Trade‑in, запис на ремонт
- **Зерно** — кав'ярня: меню, історія обсмаження, онлайн‑замовлення
- **Smile Lab** — стоматологія: послуги, лікарі, «до/після», онлайн‑запис
- **Смерека** — еко‑шале в Карпатах: режим «літо/зима», галерея, бронювання
